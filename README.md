# Momentum RL Trading Bot

A local .NET 8 console application that runs the cross-sectional momentum strategy directly against Alpaca's REST API. It does not require QuantConnect or the `alpaca-mcp-server` repository.

> **Safety:** The bot defaults to `DRY_RUN=true` and Alpaca paper trading. Review the code and paper-test before considering live trading. This is software, not financial advice.

## What it does

- Reads a configurable stock universe from `SYMBOLS`.
- Downloads daily bars from Alpaca Market Data.
- Calculates 12-1 momentum: close 21 trading days ago versus close 252 trading days ago.
- Selects the top five positive-momentum symbols.
- Supports FULL, HALF, and CASH monthly exposure actions.
- Includes the optional SPY 200-day regime state and tabular Q-learning agent.
- Rebalances on the first trading day of each month.

Alpaca does not provide the same fundamental-universe pipeline as the original QuantConnect algorithm, so this version uses an explicit universe. You can replace `SYMBOLS` with a screened list generated by your own data provider.

## Run locally

Requirements: .NET 8 SDK and an Alpaca account.

```bash
git clone https://github.com/PlayaMadeMexican/momentum-rl-trading-bot.git
cd momentum-rl-trading-bot
dotnet run --project src/MomentumRlBot
```

Set environment variables first:

```bash
export ALPACA_API_KEY=your_paper_key
export ALPACA_API_SECRET=your_paper_secret
export SYMBOLS="AAPL,MSFT,NVDA,AMZN,META,GOOGL,AVGO,AMD,TSLA,LLY,JPM,XOM,COST,WMT,ORCL,CRM,NFLX"
export DRY_RUN=true
export USE_RL=false
```

PowerShell:

```powershell
$env:ALPACA_API_KEY="your_paper_key"
$env:ALPACA_API_SECRET="your_paper_secret"
$env:SYMBOLS="AAPL,MSFT,NVDA,AMZN,META,GOOGL,AVGO,AMD,TSLA"
$env:DRY_RUN="true"
$env:USE_RL="false"
dotnet run --project src/MomentumRlBot
```

Use `ALPACA_LIVE=true` only when you intentionally want the live endpoint. The app refuses live trading unless `DRY_RUN=false` as well.

## Configuration

| Variable | Default | Meaning |
|---|---:|---|
| `ALPACA_API_KEY` | required | API key |
| `ALPACA_API_SECRET` | required | API secret |
| `ALPACA_LIVE` | `false` | Use live instead of paper API |
| `DRY_RUN` | `true` | Log orders without submitting them |
| `USE_RL` | `false` | Enable epsilon-greedy exposure agent |
| `SYMBOLS` | sample list | Comma-separated stock universe |
| `PORTFOLIO_SIZE` | `5` | Number of holdings |
| `POLL_MINUTES` | `15` | Poll interval |

The bot stores learned Q-values in `data/q-table.json`. Delete that file to reset learning.

## Important limitations

- This is a direct broker integration, not a complete QuantConnect replacement.
- The explicit symbol list replaces fundamental screening and dollar-volume ranking.
- Market orders are used for simplicity; add limit orders and stronger operational controls before live use.
- The process should run on a VPS or scheduled server during market hours, with monitoring and restart handling.
